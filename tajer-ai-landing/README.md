# تاجر AI — صفحة هبوط التحقق من الطلب

صفحة هبوط عربية (RTL) مكتفية ذاتياً لاختبار الطلب على **تاجر AI**: أداة ذكاء اصطناعي
تحوّل صور المنتجات العادية إلى صور إعلانية احترافية ونصوص تسويقية جاهزة، للبائعين العرب.

## الهدف منها (مهم)
هذه **ليست المنتج** — هي أداة قياس. قبل بناء المنتج كاملاً، نشتري إعلاناً صغيراً
ونقيس: **هل يسجّل الناس بريدهم؟** نسبة تسجيل جيدة = طلب حقيقي = نبني. نسبة ضعيفة =
نعدّل العرض قبل أن نضيّع شهوراً في البناء.

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح — لا حاجة لأي خطوة بناء.

أو شغّل خادماً بسيطاً:
```bash
cd tajer-ai-landing
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر (دقائق)
ارفع الملف على أي استضافة ثابتة مجانية: **Netlify Drop** أو **Vercel** أو **GitHub Pages**.

## قبل تشغيل الإعلانات — افعل هذه الثلاثة:
1. **اربط التقاط البريد بشيء حقيقي.** حالياً يُخزَّن البريد في `localStorage` فقط
   (انظر السكربت في آخر `index.html`). استبدله بـ Formspree أو Google Sheets أو
   خدمة بريد لتجمع العناوين فعلياً.
2. **أضف بكسل التتبع** (Meta Pixel / TikTok Pixel) وفعّل حدث `Lead` في معالج النموذج
   (هناك سطر معلّق جاهز لذلك) — لتقيس تكلفة التسجيل (CAC).
3. **جهّز إعلاناً صغيراً** ($50–100) يستهدف "بائعين على إنستغرام/تيك توك" في سوقك.

## قياس النجاح
- معدل تسجيل **> 20%** من زوّار الإعلان المستهدَف = إشارة طلب قوية → ابدأ بناء MVP.
- معدل ضعيف = عدّل العنوان/العرض/الجمهور وأعد الاختبار قبل البناء.

## الخطوة التالية بعد إثبات الطلب
بناء MVP: رفع صورة → توليد صورة إعلانية + نص تسويقي → اشتراك شهري (Stripe/Paddle).
